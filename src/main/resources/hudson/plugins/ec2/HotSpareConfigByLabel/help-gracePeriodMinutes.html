Minutes an agent of this label is given to come online, counted from the moment provisioning was requested rather than from the moment EC2 reported the instance as launched.

0 disables the grace period, which is how configurations behaved before this setting existed. When the period expires with the agent still offline, Discard agents that never come online decides whether the instance is terminated at once or kept with the idle termination clock started from the grace deadline.

This wins over the Provisioning grace period of the templates the rule matches unless Let a template override the grace period is ticked. It is also independent of the launch timeout: whichever of the two expires first wins, so a grace period longer than the launch timeout does not keep the instance alive past it.
